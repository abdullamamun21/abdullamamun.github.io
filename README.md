# Dr. Abdulla Al Mamun - Personal Academic Website

This is a free static academic website. You can publish it using GitHub Pages, Netlify, or any web hosting provider.

## Recommended free publishing method: GitHub Pages

1. Create a GitHub account at https://github.com
2. Create a new repository named: abdulla-website
3. Upload these files:
   - index.html
   - styles.css
   - CV_Abdulla_Al_Mamun.docx
4. Go to repository Settings > Pages
5. Under "Build and deployment", select "Deploy from a branch"
6. Select the main branch and root folder
7. Your website will be live at a free github.io address

## What to edit

- Replace or add your photo in the hero/about section if desired.
- Add all publications or connect a Google Scholar link.
- Add LinkedIn, ResearchGate, university profile, and personal domain if available.
- Convert CV_Abdulla_Al_Mamun.docx to PDF and replace the download link if you prefer PDF.
